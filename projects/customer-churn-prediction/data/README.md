# Dataset

Place the customer churn CSV here as `churn.csv`.

Required target column: `churn` with values `Yes`/`No` or `1`/`0`.

Recommended features:
- `customer_id`
- `tenure`
- `monthly_charges`
- `total_charges`
- `contract`
- `payment_method`
- `internet_service`
- `senior_citizen`

A public dataset such as the IBM Telco Customer Churn dataset can be used locally. Do not commit private customer information.

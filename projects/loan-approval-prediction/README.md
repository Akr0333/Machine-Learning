# Loan Approval Prediction

A practical classification project that predicts whether a loan application is likely to be approved.

## What it demonstrates
- Data preprocessing
- Missing-value handling
- Categorical encoding
- Logistic Regression
- Random Forest
- Train/test evaluation
- Precision, recall and F1-score

## Run

```bash
pip install pandas scikit-learn
python train.py
```

## Portfolio value
Shows an end-to-end supervised machine-learning workflow rather than only an isolated algorithm.
